Privacidad

Qué datos guarda el sistema de debate

La participación pública usa un alias. El email y los datos técnicos de seguridad no se muestran a otros lectores.

Datos públicos

Se publica el alias elegido, el comentario, sus respuestas y la fecha/hora. El email no se publica.

Datos técnicos privados

Al iniciar sesión o participar podemos registrar la dirección IP, navegador, sistema operativo, tipo de dispositivo, referrer, idioma, zona horaria y tamaño de pantalla. Cuando el servidor lo puede determinar, también puede registrar país, región o ciudad aproximados derivados de la IP.

No solicitamos GPS ni ubicación precisa del dispositivo.

Para qué se usan

Estos datos se usan para seguridad, prevención de abuso, spam, suplantación, amenazas, moderación y auditoría del sistema. Los metadatos técnicos son privados y sólo deben estar disponibles para administración autorizada.

Moderación

Los lectores pueden reportar comentarios. La Trama Pública puede ocultar o eliminar contenido que viole las reglas de participación, conservando los registros necesarios para auditar la medida.

Principio de minimización

El sistema debe conservar sólo los datos técnicos necesarios para seguridad y moderación y revisar periódicamente su retención. No se venden datos personales ni se publican direcciones IP.
