Comunicado de apoyo a Laura De Marinis: quiénes son los 91 firmantes

La Trama Pública organizó la nómina pública, verificó identidades y cargos cuando fue posible y conserva, para cada registro, el nivel de verificación y las fuentes utilizadas.

Cómo leer esta nota

La publicación separa los datos de la base, las fuentes y el contexto. La opinión de los lectores tendrá un espacio propio y claramente identificado.

Ir al directorio ↓

Hechos

El punto de partida

La investigación parte de un comunicado público de apoyo a Laura De Marinis en el que fueron identificados 91 firmantes.

La base conserva el nombre publicado en el comunicado y, cuando fue posible verificarlo, la identidad completa, el cargo, el organismo o dependencia, información laboral pública, el mecanismo de designación, el estado de verificación y las fuentes.

Documentos

Una base que muestra de dónde sale cada dato

Las fichas individuales enlazan la fuente principal y, cuando existe, una fuente adicional. Los datos institucionales se publican con su nivel de verificación para que el lector pueda distinguir información actual, parcial, histórica o no corroborada.

Contexto

La nómina reúne distintas funciones públicas

El comunicado fue presentado periodísticamente como una lista de “91 jueces”, pero la base distingue jueces, defensores, asesores tutelares, un fiscal, funcionarios judiciales y otras categorías. El directorio mantiene esa diferenciación en lugar de tratar a todas las personas como si ocuparan el mismo cargo.

Metodología

Cómo se construyó la base

01

Prioridad de fuentes

Primero organismos oficiales de 2026; luego documentos oficiales anteriores, publicaciones institucionales y, sólo cuando no hubo una fuente oficial nominal actual, fuentes secundarias.

02

Nivel de certeza

Cada ficha conserva una etiqueta de verificación: Verificado 2026, Parcial, Último dato anterior o No verificado.

03

Privacidad

El proyecto se limita a actividad pública e información de interés público. No se incorporan domicilios particulares, teléfonos personales, DNI/CUIT ni datos privados.

04

Imágenes

Un retrato se publica únicamente cuando la fuente y la identidad pudieron verificarse. Si existe duda, la ficha queda sin fotografía.
